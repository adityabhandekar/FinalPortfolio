roleBackend & App Developer
link view repo →
JavaSpring BootMongoDBREST APIsAndroidIoT

// overview

A mobile application and backend API built to work with a phone-independent IoT safety device. The app handles authentication, manages emergency contacts, and coordinates alerts with the device.

// problem

Emergency response often depends on a working phone. A phone-independent safety device can trigger alerts when a phone isn't accessible, and the app provides the interface to manage contacts and receive alerts.

// solution

A Spring Boot backend exposing REST APIs for authentication, emergency contacts, and alert workflows, paired with a mobile app for the user, and designed to integrate with the hardware safety device.

// features

  • User authentication (JWT)
  • Emergency contact management
  • SOS alert trigger from the app
  • Alert notifications to saved contacts
  • Location sharing during alerts
  • IoT device pairing and status
  • Phone-independent alert trigger from the device

// my contribution

  • Designed and built the mobile app
  • Built the Spring Boot backend and REST APIs
  • Implemented authentication and emergency contacts
  • Wired up the app-to-device alert workflow
